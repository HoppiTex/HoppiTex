### Stand on ai:
AI is now mostly understood as generative ai, so my takes only apply to those (normal ai is perfectly fine and necessary after all).

| Art                            | Stand                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Coding                         | I use ai for coding – i can't code what i would like to. IDK if the code is ai, it does not matter. the user experience is not altered by it and the logic is the same as if a human would make it. Code is just instructions on how something should behave and as long as a human can tell the ai how it should behave it does just not matter. AI is a great TOOL for coding, the human just has to have total overview and control of how it behaves in the end.                                                                                                       |
| Image                          | Personally I don't mind using ai imagery to test image descriptions – i do that and it does help somewhat, though i do not use it for anything else as ai cannot create my visions (its too incompitent).<br>My opinion is that if you only use AI generated art for personal use or for placeholders or for free assets in a free project, then I think it is okay. If it is in marketing or a paid product or somewhere you can see it very easily and it is something that signals someone that this is what you are doing, then it is in my opinion definitely not ok! |
| TTS                            | I HATE IT. TTS is only good for badly reading text on the fly – which can already archieved via prerecorded samples or computer wavelengths (normal TTS). AI just can't do that. it just sounds wrong and voice cloning..... i think its just wrong. it just sounds ass. i'd rather listen to the worst old TTS than some AI TTS.                                                                                                                                                                                                                                          |
| audio                          | no, just no. if you genererate music or songs with ai: GET OUT. i have no respect for you and i do not want anything to do with you.                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Writing                        | If you just use it to correct your own writing or make it just a little better WHILE preserving your own writing style: Perfect!<br>If you generate yourself shitty stories without any actual involement...... no, no – get out and don't come back.                                                                                                                                                                                                                                                                                                                      |
| analysing, dynamic things, etc | Yea thats good, thats a good use case. I use it like that sometimes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
