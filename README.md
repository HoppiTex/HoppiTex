#### Stand on ai art generation:
Personally i like toying with image generation as it is fun to see what they can do.
My opinion is that if you only use ai generated art for personal use or for placeholders or for free assets in a free project, then i think it is okey. If it is in marketing or a paid product or somewhere you can see it very easely and it is something that signals someone that this is what you are doing, then it is in my opinion defenetally not ok!
